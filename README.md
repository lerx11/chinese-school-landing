# 🚀 Chinese School Landing Page

Одностраничный лендинг для школы китайского языка для детей 5–12 лет.

## 📌 Особенности

- Космическая тематика с анимацией звёзд и ракеты
- 8 уровней-планет в дорожной карте (горизонтальный скролл)
- Анимированный счётчик учеников
- Glassmorphism-карточки кейсов
- 3 тарифа с выделенным "оптимальным"
- Форма с маской телефона и выбором мессенджера
- Аккордеон FAQ
- Полная адаптивность (Mobile First)
- ARIA-атрибуты и доступность

## 🛠 Технологии

- HTML5 / CSS3 (CSS-переменные, Flexbox, Grid)
- JavaScript (без библиотек)
- Font Awesome и Google Fonts (CDN)
- GitHub Pages для хостинга
